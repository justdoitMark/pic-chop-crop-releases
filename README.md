# Pic Chop Crop — загрузка

Pic Chop Crop — быстрая обрезка картинок под точный размер (W×H) для Windows 10/11 (x64).

**Скачать:** [последняя версия](https://github.com/justdoitMark/pic-chop-crop-releases/releases/latest) → файл `Pic.Chop.Crop_…_x64-setup.exe`.

- Установка обычная: «Далее → Далее». Windows может показать синее окно «Windows protected your PC» (у приложения нет платной цифровой подписи): «Подробнее» → «Выполнить в любом случае».
- С версии 0.2.0 обновления приходят сами (проверка при запуске или значок в трее → «Проверить обновления»). Каждое обновление подписано, и приложение не установит файл с чужой подписью.
- Картинки никуда не отправляются: в сеть уходит только проверка обновлений на GitHub.

Здесь только установщики. Исходный код приложения закрыт; архивы «Source code» в выпусках содержат только этот README.
